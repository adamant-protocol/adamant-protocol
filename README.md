# Adamant Protocol

A Layer 1 blockchain protocol designed to serve users who require properties no existing programmable chain delivers in combination.

Privacy by default. Post-quantum cryptographic security. Sub-second finality. Encrypted mempool. Phone-verifiable state. No foundation, no premine, no admin keys, no governance.

## Status

Pre-launch. Specification complete. Reference implementation in progress.
